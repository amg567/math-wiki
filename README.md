# MathWiki

MathWiki is an open, modern mathematics encyclopedia that organizes topics by academic level and branch so learners can explore concepts in a clear progression.

## Live project

- GitHub repository: https://github.com/amg567/math-wiki

## Features

- Browse math topics by level (High School, Undergraduate, Master's, PhD)
- Explore branches and connected concepts
- Search for topics quickly
- Save bookmarks for frequently visited pages
- View a clean, modern interface with light/dark theme support

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting started

1. Install dependencies:
   - `npm install --legacy-peer-deps`
2. Start development server:
   - `npm run dev`
3. Open `http://localhost:3000`

## Build and run

- Build for production: `npm run build`
- Start production server: `npm run start`

## Lint

- Run lint checks: `npm run lint`
